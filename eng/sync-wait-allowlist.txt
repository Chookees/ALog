# Sync waits that stay in ALog. Each line is path:regex # reason.
# The reason names the timeout and why the caller SynchronizationContext is not captured.
# eng/sync-wait-check.py fails when a library hit is missing here, or a line here matches nothing.

ALog/Core/BackgroundLogQueue.cs:GetAwaiter\(\)\.GetResult\(\) # Only the queue's own consumer thread blocks here, on the task from DispatchAsync or from a non-file writer during a replay. A completed faulted task is waited too, because that is how a deferred write is seen. A log call never reaches this line and no caller SynchronizationContext is captured. Timeout: the writer task itself; FlushTimeout stops new writer calls and does not cancel a call that has already started.
ALog/Core/BackgroundLogQueue.cs:_wake\.Wait\(\) # Only the queue's own consumer thread waits here. A log call sets the event and does not run this wait, so the caller SynchronizationContext is not captured. Timeout: the configured flush interval on the injected clock, or sooner when a log call or shutdown sets the event.
ALog/Core/BackgroundLogQueue.cs:waiter!\.Signal\.WaitHandle # A Block caller waits until the queue accepts the event or dispose releases it. The logging thread is the caller, and its SynchronizationContext is not captured. Timeout: FlushTimeout on the injected clock. Dispose signals the waiter.
ALog/Core/BackgroundLogQueue.cs:_releaseRetry\.WaitHandle # Only the queue's own consumer thread waits here for a failed file reopen. A log call does not run this wait. Timeout: the retry delay on the injected clock, or shutdown sets _releaseRetry.
ALog/Core/BackgroundLogQueue.cs:signaled\.WaitHandle, wake\.WaitHandle # The disposing thread waits for the processor or the shutdown deadline. The caller SynchronizationContext is not captured. Timeout: the due TimeSpan on the injected clock.
ALog/Writers/Cloud/AwsCloudWatchWriter.cs:GetResult\( # The AWS SDK has no synchronous API. The put starts on the thread pool, so the caller SynchronizationContext is not captured. Timeout: 100 seconds, the default HTTP client timeout used when the SDK client timeout is unset.
